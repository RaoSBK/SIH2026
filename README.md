# Criminal Intelligence Platform

A comprehensive intelligence platform for law enforcement and criminal investigation.

## Sub-projects

- `frontend/`: React + TypeScript frontend application.
- `backend/`: FastAPI backend service.
- `ml/`: Machine Learning and NLP pipelines (entity resolution, anomaly detection, relationship extraction).
- `graph/`: Ontology, Cypher schemas, and graph analytics service.
- `blockchain/`: Hyperledger Fabric client for evidence integrity verification.
- `infrastructure/`: Docker, Nginx, and monitoring setups.
